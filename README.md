# Терминал самообслуживания для ресторанов

Фронтенд терминала заказа: экран гостя для планшета и панель персонала. Vue 3, Pinia, Vite, без UI-библиотек.

Бэкенд в репозиторий не входит: терминал работает с внешним API по REST и WebSocket, меню и заказы синхронизируются с системой учёта iiko.

## Возможности

**Экран гостя.** Приветственный экран с настраиваемой заставкой, меню с категориями и фильтрами, карточки блюд с составом и ценой, корзина, рекомендации к заказу, вызов официанта, подтверждение заказа с номером и выбором стола.

**Панель персонала** (`/admin`). Таблица заказов с фильтрами и сменой статусов, управление меню и категориями, редактирование позиций, управление устройствами (статус терминалов, удалённое обновление APK), настройки уведомлений, параметры интеграции и переключение режима сервера. Вход в панель закрыт паролем администратора.

**Обновления в реальном времени.** Отдельные WebSocket-каналы для заказов, уведомлений, меню, изображений и статуса устройств. Каждый канал переподключается автоматически (до пяти попыток), состояние связи видно в интерфейсе.

## Стек

Vue 3 (Composition API), Pinia, Vue Router, Vite, нативный WebSocket API, ESLint и Prettier. Интерфейс рассчитан на планшеты, сборка упаковывается в приложение под Android.

## Структура

```
src/
  views/              Greetings, Main, Orders (админ-панель), Register
  components/
    MainPage/         меню, карточки блюд, корзина, попапы заказа и вызова официанта
    OrdersPage/       таблица заказов, управление меню, категориями, устройствами, настройками
    common/           переиспользуемые элементы и индикатор состояния WebSocket
  stores/             orders, menu, images, device, waiter, settings, auth, apiConfig, websocket
  hooks/              работа с API, авторизация администратора, настройки заставки
scripts/start.cjs     запуск с выбором режима сервера
```

## Запуск

```bash
npm install
npm run dev     # спросит режим: локальный сервер для разработки или публичный
npm run build
```

Режим сервера переключается и из панели персонала, адрес API хранится в конфигурации приложения.
